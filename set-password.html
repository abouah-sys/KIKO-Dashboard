🔑 Set the team password

Type the password you want to use, click Generate, then copy the code and paste it into assets/js/config.js.

  1. Open assets/js/config.js.
  2. Replace the text after PASSWORD_HASH: with the copied code (keep the quotes).
  3. Save and re-deploy the site.
  4. Delete or ignore this set-password.html page — it's just a helper.
